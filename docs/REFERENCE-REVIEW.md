# Reference website review

Reviewed on 12 September 2026 at the user's request:

- [Biodata editor](https://freebiodatamaker.com/#create-biodata)
- [Template gallery](https://freebiodatamaker.com/templates/)

The public editor has language selection, personal/family/contact steps, optional photo upload, optional field inclusion, and an Add New Field control. The public gallery lists 27 designs across abstract, velvet, floral, green, and classic styles. Its FAQ distinguishes free basic templates from paid premium options.

## Applied to BioResume

The existing five designs remain, and 27 additional original CSS/SVG themes cover those gallery styles. All 32 are free. No artwork, source code, logos, user photos, or paid assets from the reference site are included.

The editor adds short/long custom fields, renaming, removal with undo, up/down movement, and movement between sections. These edits change the shared document model, so preview, PDF, and saved drafts stay consistent.

The requested language set is English, Hindi, Marathi, Gujarati, and Nepali. Standard labels and PDF headings are localized; entered content is preserved. Fonts are served locally. Language selection does not translate a user's name or convert Gregorian dates to a different calendar.

The heading controls follow the requested workflow: Biodata Title, Selected God / Change God Photo, and an editable God Name / blessing. BioResume uses three newly generated devotional images and a newly generated botanical paper background, plus original CSS paper treatments. No reference artwork was copied. [Asset files and exact generation prompts](ARTWORK.md) document their origin.

Backgrounds are independent of templates and can be replaced with a personal image. Users can fit content to a single page, choose a target page count, or use automatic pagination. Word downloads, payments, advertising, and account features remain outside this release. The Ganesha, lotus, and temple theme ornaments remain original inline vectors.
